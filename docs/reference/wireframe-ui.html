3 · Cấp Vibe Host gắn tài khoản

  • Kích hoạt ngay khi BTC duyệt: Cổng gọi Hạ tầng tạo tài khoản + Vibe Host.
  • Mặc định 1 website + 1 database; hiệu lực = thời gian thi (không phải Trial 7 ngày).
  • Cổng biết sẵn URL → nộp bài gần như tự động; thu hồi/đối soát theo tài khoản.
